データと利用上の注意

気候データ：NASA Langley Research Center POWER Project。全球分布図は公開AWS Zarrの月別データから1991年1月〜2020年12月を独自集計し、地点詳細はClimatology API / Daily APIから取得しています。降水量は日平均量に各月・年の日数を掛けて月降水量・年降水量へ換算しています。NASAは本ツールを承認または推奨するものではありません。

橙枠は、クリック位置に最も近いNASA POWER気象格子の中心に合わせた約0.5°×0.625°の範囲です。白い小点は格子中心です。気温・降水量・相対湿度は橙枠に対応する元格子の空間平均を示します。日射量は同じ中心点に対応する別の1°×1°格子の値で、橙枠とは範囲が異なります。

気候区分：Beckほか（2023）ケッペン＝ガイガー気候区分の1991–2020年・0.1°版（CC0）をWebメルカトルへ再投影しています。区分境界付近には不確実性があります。

地図境界・国名・首都：Natural Earth 1:50m Admin 0 Countries / 1:10m Populated Places（Public Domain）。格子中心が属する国・地域を表示します。境界・名称表示は法的立場を示すものではありません。

本ツールは広域の気候傾向を確認する試作版です。局地的な地形、都市、沿岸、標高、品種、栽培環境の差は表現しません。栽培可否の断定には使用しないでください。

プライバシー

Cookie、アクセス解析、現在地取得、入力情報の保存は行いません。地図をクリックすると、気象格子の中心座標と通常の通信情報が気候データ取得のためNASA POWERへ送信されます。
